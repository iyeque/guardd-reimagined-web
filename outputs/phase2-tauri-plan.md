# Phase 2: Desktop App (Tauri) — Plan

## Status: Scaffolded (config + Rust skeleton written, Rust not yet installed)

## What's done
- `src-tauri/tauri.conf.json` — Tauri v2 config (product name, window, CSP, bundle targets, no signing)
- `src-tauri/Cargo.toml` — Rust dependencies (tauri 2, shell plugin, serde, tokio)
- `src-tauri/src/main.rs` — Rust entry point with hosts-file blocking commands (`block_domains`, `unblock_all`)

## What's needed to build

### 1. Install Rust toolchain
```bash
winget install Rustlang.Rustup
# or download from https://rustup.rs
rustup default stable
```

### 2. Install Tauri CLI
```bash
npm install -D @tauri-apps/cli
```

### 3. Add Tauri scripts to package.json
```json
"tauri": "tauri",
"tauri:dev": "tauri dev",
"tauri:build": "tauri build"
```

### 4. Build
```bash
npm run tauri:build
# Produces: src-tauri/target/release/bundle/ (msi on Windows, dmg on macOS)
```

## Enforcement (desktop)
- **Hosts file modification** (`/etc/hosts` on macOS/Linux, `C:\Windows\System32\drivers\etc\hosts` on Windows)
- Digital Guardian writes a marked block between `# >>> Digital Guardian START <<<` and `# >>> Digital Guardian END <<<`
- Blocked domains redirect to 127.0.0.1 (connection refused → browser shows error)
- Re-evaluated at every window boundary (same alarm logic as extension)
- Cleanup on app close (remove marked block)

## Limitations without code signing
- **Windows:** SmartScreen warning on download (users can click "More info → Run anyway")
- **macOS:** Gatekeeper blocks entirely (users must right-click → Open, or System Settings → Security → "Open Anyway")
- **Auto-updater:** Tauri updater requires a signing keypair (free, generated by `tauri signer generate`); unsigned updates are refused by design
